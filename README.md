# مساعدي اليومي — Android 2.0

تطبيق Android عربي RTL مبني بـ Kotlin وJetpack Compose لإدارة تفاصيل اليوم في مكان واحد.

## الوظائف المكتملة

- لوحة رئيسية ديناميكية مرتبطة بالبيانات الفعلية.
- أهداف كاملة: إضافة، تعديل، حذف، وتغيير نسبة الإنجاز بالسحب.
- أفكار: إضافة، تعديل، حذف، بحث، ومفضلة.
- ملاحظات: إضافة، تعديل، حذف، بحث، وتثبيت.
- متتبع عادات أسبوعي: إنشاء عادات وتعديلها وحذفها وتسجيل كل يوم وتصفير الأسبوع.
- معرض صور محلي مع الاحتفاظ بصلاحية الوصول للصورة وإزالة الخلفية للشخص باستخدام ML Kit Selfie Segmentation.
- تعيين صورة رئيسية تظهر في الصفحة الرئيسية والملف الشخصي.
- يوميات يومية: مزاج، امتنان، تركيز، حفظ ومشاركة.
- إعدادات: الاسم، الوضع الداكن، التذكير اليومي واختبار الإشعار.
- إعادة جدولة التذكير بعد إعادة تشغيل الهاتف.
- مشاركة ملخص البيانات محلياً.
- إعادة ضبط كاملة للتطبيق مع تأكيد.
- جميع البيانات الأساسية محفوظة محلياً عبر SharedPreferences/JSON بدون حساب أو خادم.

## البناء

GitHub Actions يبني APK قابل للتثبيت عند كل Push إلى `main` ويرفعه كـ Artifact باسم `masaedi-alyoumi-v2.0.0`.

> APK الناتج من CI هو build تثبيت/اختبار موقّع بمفتاح Android debug. للنشر في Google Play يلزم مفتاح توقيع إنتاجي خاص بصاحب التطبيق.
