# مساعدي اليومي — Android 3.0

تطبيق Android عربي RTL مبني بـ Kotlin وJetpack Compose ليكون مساحة يومية شخصية للأهداف، العادات، الصور، الأفكار، الملاحظات واليوميات.

## ما تغيّر في 3.0

- لوحة يومية موحدة تعرض تقدم اليوم من الأهداف والعادات واليوميات.
- إبراز صورة المستخدم كشخصية مدمجة في الواجهة عبر ML Kit Selfie Segmentation.
- أهداف محسنة: تصنيفات، موعد اختياري، تقدم مباشر، حالة مكتمل/قيد التنفيذ، بحث وفلاتر.
- عادات بسجل تواريخ حقيقي بدلاً من أسبوع ثابت فقط، مع السلسلة الحالية وأفضل سلسلة وآخر 7 أيام.
- معرض شخصيات متقدم: صورة رئيسية، مفضلة، تعليق لكل صورة، عرض بارز، وإزالة محلية آمنة.
- أفكار مع بحث، تصنيف ومفضلة.
- ملاحظات قابلة للتثبيت مع ألوان بطاقات متعددة.
- يوميات بأرشيف متعدد الأيام: مزاج، امتنان، تركيز، تفاصيل اليوم، والرجوع للسجلات السابقة.
- إضافة سريعة من الزر المركزي للأهداف والأفكار والملاحظات والعادات، مع وصول سريع للصور واليوميات.
- إعدادات محسنة للملف الشخصي، الوضع الداكن، وقت التذكير، اختبار الإشعار، مشاركة الملخص وإعادة الضبط.
- ترحيل قدر الإمكان لبيانات نسخة 2.x الحالية بدلاً من البدء من الصفر.
- حفظ البيانات الأساسية محلياً عبر SharedPreferences/JSON بدون اشتراط حساب أو خادم.

## البناء

GitHub Actions يبني APK قابل للتثبيت عند التحديث ويرفعه كـ Artifact باسم `masaedi-alyoumi-v3.0.0`.

> ملف APK الناتج من CI موقّع بمفتاح Android debug ومخصص للتثبيت والاختبار المباشر. النشر الرسمي على Google Play يتطلب مفتاح توقيع إنتاجي خاص بصاحب التطبيق.
