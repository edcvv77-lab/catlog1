# مساعدي اليومي — Daily Companion

تطبيق Android عربي أصلي (Native) مبني بـ Kotlin وJetpack Compose، بواجهة RTL مستوحاة من التصميم المتفق عليه.

## المزايا الحالية

- لوحة رئيسية عربية بتصميم أبيض/بنفسجي وبطاقات ناعمة.
- أهداف يومية مع نسب إنجاز قابلة للتحديث والحفظ محلياً.
- أفكار ملهمة مع إمكانية إضافة أفكار جديدة.
- ملاحظات لحظية قابلة للحفظ.
- متتبع سلوك أسبوعي تفاعلي.
- قسم «صوري» لاختيار الصور من الجهاز وفصل خلفية الشخص تلقائياً على الجهاز، لتظهر الشخصية بارزة كجزء من الواجهة.
- صورة تجريبية واسم افتراضي «محمد حافظ» لتطابق النموذج المرئي.
- تذكرة تحفيزية داخل التطبيق.
- تعديل اسم المستخدم.
- حفظ البيانات محلياً دون الحاجة إلى خادم خارجي.

## APK

GitHub Actions يبني نسخة Debug قابلة للتثبيت تلقائياً عند كل تحديث على فرع `main`، ويرفعها كـ artifact باسم `daily-companion-apk`.

## التقنية

- Kotlin 2.3.21
- Android Gradle Plugin 8.11.1
- Jetpack Compose / Material 3
- Android API 36
- ML Kit Selfie Segmentation لفصل خلفية الصور
